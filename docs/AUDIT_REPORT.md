# تقرير المراجعة والتطوير — تطبيق بلاغات سيئون

**النطاق:** تطبيق Flutter في هذا المستودع فقط. خادم Laravel (`medicalhouse-ye.net/api`) ولوحة الإدارة
**غير موجودين في المستودع**، فلم يتم فحصهما أو تعديلهما؛ متطلباتهما في `docs/BACKEND_REQUIREMENTS.md`.

لم يُعثر في كود Flutter على: طباعة كلمات مرور أو رموز في السجلات، مفاتيح API سرية
(مفاتيح Firebase الموجودة عامة بطبيعتها ويجب تقييدها من Google Cloud Console)، أو استعلامات SQL مبنية
بدمج نصوص المستخدم (sqflite يستخدم معاملات).

## 2. ما لم يُنفَّذ ولماذا
- **IDOR، SQL Injection، الصلاحيات، Rate limiting، تجزئة كلمات المرور، الفهارس، النسخ الاحتياطي، سجل العمليات، لوحة الإدارة:**
  كلها على الخادم غير الموجود هنا. التطبيق لا يستطيع ضمانها، وتطبيقها في Flutter فقط لن يحمي شيئاً.
- **رمز OTP من 6 أرقام:** يتطلب خادماً يرسل البريد؛ استُخدم رابط Firebase الآمن بدلاً منه.
- **دور Admin/Super Admin في التطبيق:** لا توجد واجهات إدارة في تطبيق الجوال (لوحة الإدارة خارجه)، لذا لم أُنشئ شاشات إدارة وهمية.
- **الدفع الإلكتروني:** لا توجد بوابة؛ جُهزت الواجهة البرمجية `PaymentGateway` فقط.
- **إعادة تصميم الواجهات بالكامل:** حُسّنت الشاشات المتأثرة فقط للحفاظ على الهوية الحالية.
- **اختبارات التكامل (Integration) واختبارات الأداء:** تحتاج جهازاً/محاكياً وحسابات Firebase اختبارية — لم تُنفَّذ.
