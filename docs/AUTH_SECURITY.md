# نظام المصادقة — التصميم والمتطلبات

## البنية
- **مزوّد الهوية:** Firebase Authentication (بريد/كلمة مرور + Google).
- **خادم التطبيق:** Laravel على `medicalhouse-ye.net/api` (غير موجود في هذا المستودع).
- **التدفق:** إنشاء حساب ← إرسال رابط تحقق ← المستخدم يفتح الرابط ← التطبيق يتأكد من `emailVerified`
  ← يُرسَل `idToken` إلى `POST /login` ← الخادم يعيد رمز وصول يُخزَّن في Keystore/Keychain.

## ما يطبّقه التطبيق
| المتطلب | التنفيذ |
|---|---|
| صيغة البريد | `AuthValidators.checkEmailFormat` (حدود RFC، نطاقات مؤقتة، تصحيح أخطاء شائعة) |
| نطاق البريد / MX | `domainAcceptsMail` عبر DNS-over-HTTPS (يُرسل اسم النطاق فقط). لا يمنع المستخدم إذا تعذّر الفحص |
| إثبات الملكية | رابط تحقق من Firebase؛ لا تسجيل لدى الخادم قبل التفعيل |
| صلاحية / عدم إعادة الاستخدام | يديرها Firebase (رمز `oobCode` يُستخدم مرة واحدة وله مدة صلاحية) |
| إعادة الإرسال وفترة الانتظار | `ActionCooldown`: 60 ← 120 ← 300 ← 600 ثانية، وحد أقصى 5 طلبات في الساعة |
| منع الإغراق | الحد في التطبيق + حد Firebase على الخادم (`too-many-requests`) |
| محاولات الدخول | إيقاف مؤقت متصاعد بعد 5 محاولات فاشلة + حماية Firebase |
| عدم كشف الحسابات | رسالة موحّدة لفشل الدخول؛ استعادة كلمة المرور تعرض نفس الرسالة دائماً |
| الجلسات | رمز Firebase يتجدد تلقائياً؛ عند استجابة 401 يُجدَّد رمز الخادم مرة واحدة ثم يُعاد الطلب، وإلا تُنهى الجلسة |
| فحص الجلسة عند الفتح | `validateRemoteSession` يكتشف الحساب المحذوف/المعطّل/الجلسة الملغاة |
| تسجيل الخروج | `SessionManager.logout`: `POST /logout` (إن وُجد) + Google + Firebase + مسح التخزين الآمن والمحلي |
| الصفحات المحمية | شاشة البداية توجّه حسب الحالة؛ `AuthGuard` يحمي المسارات المسماة |

## ⚠️ مطلوب على خادم Laravel (لا يمكن ضمانه من التطبيق)
1. التحقق من `idToken` باستخدام Firebase Admin SDK (مثل `kreait/laravel-firebase`)، ورفض أي طلب لا يحمل رمزاً صالحاً.
2. رفض الدخول إذا كان `email_verified != true` (عدا مزوّد `google.com`).
3. أخذ البريد والمعرّف (`uid`) من الرمز المتحقَّق منه فقط، **وعدم الوثوق** بحقلي `email` و`role` في جسم الطلب. الدور يحدده الخادم.
4. إصدار رموز Sanctum بمدة صلاحية (`expiration` في `config/sanctum.php`) وإضافة `POST /logout` يحذف الرمز الحالي.
5. Rate limiting على `/login` (مثل `throttle:10,1`).

## ⚙️ إعدادات Firebase Console
- Authentication ← Settings ← **Email enumeration protection: تفعيل**.
- Authentication ← Settings ← **Password policy**: 8 أحرف على الأقل مع حروف وأرقام (يطابق سياسة التطبيق).
- Authentication ← Templates: تعريب قالبي "Email address verification" و"Password reset" وضبط اسم المرسل.
- إضافة نطاق مخصص للمرسل (SPF/DKIM) لتقليل وصول الرسائل إلى البريد المزعج.

## قيود معروفة
- التحقق يتم **برابط** وليس برمز OTP من 6 أرقام: رمز OTP يتطلب خادماً يولّد الرمز ويخزّن تجزئته ويرسل البريد
  (Laravel أو Cloud Functions)، وهو غير موجود في هذا المستودع.
- إعادة تعيين كلمة المرور تتم في صفحة Firebase المستضافة؛ لإتمامها داخل التطبيق يلزم إعداد
  Deep Links / App Links واستخدام `confirmPasswordReset`.
